# 🐴 OnlyHorse – E-Commerce Store

A modern full-stack e-commerce application built with **Next.js 16**, **React 19**, **TypeScript**, **Prisma**, **PostgreSQL (Neon)**, **Kinde Authentication**, **Stripe**, and **Cloudinary**.

🌐 **Live Demo:** https://onlyhorse-e-commerce-store.vercel.app/

💻 **GitHub:** https://github.com/asia272/onlyfans

---

## ✨ Features

* 🔐 Kinde Authentication (Login/Logout)
* 👤 User Profile Management
* 💳 Stripe Monthly & Yearly Subscriptions
* 🛍️ Merchandise Store
* ❤️ Like & Comment System
* ☁️ Cloudinary Image Uploads
* 🌙 Dark & Light Theme
* 📱 Fully Responsive Design
* ⚡ Secure Server Actions & API Routes

## 🚀 Getting Started

```bash
git clone https://github.com/asia272/onlyfans.git

cd onlyfans

npm install

npx prisma generate

npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file and add:

```env
DATABASE_URL=

KINDE_CLIENT_ID=
KINDE_CLIENT_SECRET=
KINDE_ISSUER_URL=

STRIPE_SECRET_KEY=
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=
STRIPE_WEBHOOK_SECRET=

NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_SECRET=
```
